# Vidraçaria CRUD

Sistema de cadastro de vidros com Flask

## Estrutura

```
.
├── app.py               # Servidor Flask (rotas + lógica)
├── crudcodigo.py        # CLI standalone para testes no terminal
├── requirements.txt     # Dependências Python
└── templates/
    ├── base.html        # Layout base (header, flash, footer)
    ├── index.html       # Lista de vidros
    └── form.html        # Formulário de cadastro/edição
```

## Como rodar

```bash
# 1. Instalar dependências
pip install -r requirements.txt

# 2. Iniciar o servidor
python app.py
```

Acesse em: http://127.0.0.1:5000

## CLI (opcional)

Para testar as operações CRUD direto no terminal, sem precisar do servidor:

```bash
python crudcodigo.py
```
